colofon es un monorepo de TypeScript que corre sobre Bun y se coordina con
Turborepo. El navegador solo habla con el gateway, que manda la API, el MCP y
el servidor git al backend y todo lo demás al frontend.

## Las piezas

<Entities type="workspaces" group="kind" />

- **Las apps** (`apps/`) son lo que se ejecuta. `apps/frontend` es la web:
  Astro 7 renderiza las páginas en el servidor (SSR) y monta componentes
  React 19 como islas para la parte interactiva, con Tailwind v4 y shadcn/ui
  sobre Base UI; habla con la API mediante un cliente oRPC tipado y TanStack
  Query. `apps/backend` es la API: un servidor Hono sobre Bun que monta los
  procedimientos de `packages/api`, el MCP de documentación (`/mcp`) y el
  servidor git de los repositorios alojados (`/git/…`). `apps/site` es la web
  estática del proyecto, que se publica en GitHub Pages y no forma parte de la
  app en marcha.
- **Los paquetes** (`packages/`) son librerías compartidas con el prefijo
  `@nonete/`. `@nonete/content` lee y valida los repositorios de contenido (ver
  [Contenido](../contenido/index.mdx)); el resto (API, autenticación, base de
  datos, crons, logger, entorno y `tsconfig` base) son los de cualquier
  proyecto de la plantilla.
- **Lo que no es workspace** no tiene `package.json`: el gateway (`apps/gateway`)
  solo tiene las rutas de Caddy (`routes.caddy`), el `Caddyfile` de
  producción, el `Caddyfile.dev` de desarrollo, su `compose.yml` y su
  `Dockerfile`.

Además de las apps, el backend usa una base de datos PostgreSQL (con Drizzle)
y guarda en disco, bajo la raíz del repositorio, los clones de los
repositorios de contenido (`.content/`) y los repositorios que aloja la propia
plataforma (`.hosted/`); en Docker son los volúmenes `content_data` y
`hosted_data`.

## Los paquetes no se compilan

Cada paquete se publica como código TypeScript tal cual y las apps lo importan
directamente: su script `build` es literalmente `true`. Así no hay pasos
intermedios y cualquier cambio en un paquete se ve al momento en la app que lo
usa. Solo se compilan las apps: el backend con `tsdown` y el frontend con
`astro build`.
