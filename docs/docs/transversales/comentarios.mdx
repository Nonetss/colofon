Para usarlos en una entidad basta con renderizar `CommentsButton` (de
`@/features/comments`) con la referencia de la entidad en su prop `entity`
(su `entityType` y su `entityId`). Muestra el contador y abre el hilo en un
panel lateral. **Hoy ninguna pantalla de colofon lo usa.**

```tsx
<CommentsButton entity={{ entityType: "content-repository", entityId: repository.id }} />
```

## Las piezas del frontend

| Pieza | Qué es |
| --- | --- |
| `CommentsButton` | El botón con el contador que abre el panel. Con `compact` es un botón de solo icono. Si la lista ya tiene los contadores, se le pasa `count` y no pide el suyo. |
| `CommentsSheet` | El panel lateral con el hilo |
| `CommentsPanel` | El hilo sin el panel, para meterlo en otra caja |
| `useCommentCounts` | Los contadores de muchas entidades en una sola consulta, para una lista |
| `useCommentCount` | El contador de una entidad |

## La API

`orpc.v1.comment.*`, todos con `protectedProcedure` (hace falta sesión o API
key):

| Procedimiento | Método | Qué hace |
| --- | --- | --- |
| `list` | `GET` | Los comentarios de una entidad, como árbol de respuestas. Un comentario borrado sin respuestas visibles no sale; con respuestas, sale vacío. |
| `counts` | `QUERY` | Cuántos tiene cada una de hasta 100 entidades a la vez, para los contadores de una lista. |
| `create` | `POST` 201 | Crea un comentario o, con `parentId`, una respuesta. Hasta 4000 caracteres. |
| `update` | `PATCH` | Cambia su contenido. |
| `delete` | `DELETE` | Lo borra de forma lógica (`deleted_at`); repetirlo no da error. |

Solo el autor puede editar o borrar sus comentarios. Los comentarios viven en
la tabla `comments`; `entity_id` es un UUID, así que solo se pueden comentar
entidades con id UUID.

## Qué falla

| Mensaje | Causa |
| --- | --- |
| «Solo puedes editar tus comentarios» / «Solo puedes eliminar tus comentarios» (`FORBIDDEN`) | No eres el autor |
| «Comentario no encontrado» (`NOT_FOUND`) | El comentario no existe o ya está borrado |
| «Comentario padre no encontrado» (`NOT_FOUND`) | La respuesta apunta a un comentario que no existe o está borrado |
| «El comentario padre pertenece a otra entidad» (`BAD_REQUEST`) | La respuesta y su padre son de entidades distintas |
| Error de validación al comentar una entidad | Su id no es un UUID |

<Callout type="warning">
Al borrar una entidad que tiene comentarios, su handler tiene que borrarlos en
la misma transacción: la referencia es polimórfica y la base de datos no lo
hace sola (ver [Referencias polimórficas](index.mdx#referencias-polimórficas)).
</Callout>
