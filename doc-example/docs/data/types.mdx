## Una declaración

```yaml
# catalog/machines/_type.yaml
name: Máquina            # singular
plural: Máquinas
icon: server              # el nombre de un icono de Lucide
description: Servidores, VM y VPS. El id es el hostname en minúsculas

title_field: name             # el campo que se muestra como nombre de cada entidad; sin él, el id

fields:
  name:
    type: text
    optional: true
    description: Solo cuando se escribe distinto del id (PVE-01)
  ip:
    type: ip
  location:
    type: ref
    to: locations
  kind:
    type: enum
    values: [physical, vm, vps]

view:
  columns: [name, ip, kind, location]   # la tabla del tipo
```

- **El id del tipo** es el nombre de su carpeta: minúsculas, dígitos y guiones.
- **Los nombres de campo** son minúsculas, dígitos y guiones bajos, y empiezan por una letra.
- **Todo campo es obligatorio** salvo que diga `optional: true`.
- **`description` en todo campo que no sea obvio:** el editor la muestra como ayuda y los agentes la leen.
- `title_field` y cada columna de `view.columns` deben ser campos declarados; las columnas también aceptan `id`, `source` y `updated`.
- `source` y `updated` nunca se declaran: toda entidad los acepta.
- `_type.yaml` es una declaración: mientras una esté rota, la plataforma conserva la última versión válida de cada declaración.

## Tipos de campo

<Entities type="field-kinds" group="family" columns="id,value,takes,example" />

Los tipos se anidan: una `list` de `object`, cada uno con otra `list`, es válida.

```yaml
containers:
  type: list
  of:
    type: object
    fields:
      name: { type: text }
      ports:
        type: list
        optional: true
        of: { type: text }
        description: Publicado:interno (8080:80)
```

Los mismos tipos declaran los campos extra de la cabecera de [`doc.config.yaml`](../repository/config.mdx).

## Antes de añadir uno

- Busca un tipo existente que encaje; crea uno solo cuando ninguno sirva.
- Tras cambiar un `_type.yaml`, las entidades existentes deben seguir validando: un campo obligatorio nuevo tiene que rellenarse en todas ellas.
