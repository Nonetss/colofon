## Una declaración

```yaml
# catalog/machines/_type.yaml
nombre: Máquina            # singular
plural: Máquinas
icono: server              # el nombre de un icono de Lucide
descripcion: Servidores, VM y VPS. El id es el hostname en minúsculas

etiqueta: name             # el campo que se muestra como nombre de cada entidad; sin él, el id

campos:
  name:
    tipo: texto
    opcional: true
    descripcion: Solo cuando se escribe distinto del id (PVE-01)
  ip:
    tipo: ip
  location:
    tipo: ref
    a: locations
  kind:
    tipo: enum
    valores: [physical, vm, vps]

vista:
  columnas: [name, ip, kind, location]   # la tabla del tipo
```

- **El id del tipo** es el nombre de su carpeta: minúsculas, dígitos y guiones.
- **Los nombres de campo** son minúsculas, dígitos y guiones bajos, y empiezan por una letra.
- **Todo campo es obligatorio** salvo que diga `opcional: true`.
- **`descripcion` en todo campo que no sea obvio:** el editor la muestra como ayuda y los agentes la leen.
- `etiqueta` y cada columna de `vista.columnas` deben ser campos declarados; las columnas también aceptan `id`, `fuente` y `actualizado`.
- `fuente` y `actualizado` nunca se declaran: toda entidad los acepta.
- `_type.yaml` es una declaración: mientras una esté rota, la plataforma conserva la última versión válida de cada declaración.

## Tipos de campo

<Entities type="field-kinds" group="family" columns="id,value,takes,example" />

Los tipos se anidan: una `lista` de `objeto`, cada uno con otra `lista`, es válida.

```yaml
containers:
  tipo: lista
  de:
    tipo: objeto
    campos:
      name: { tipo: texto }
      ports:
        tipo: lista
        opcional: true
        de: { tipo: texto }
        descripcion: Publicado:interno (8080:80)
```

Los mismos tipos declaran los campos extra de la cabecera de [`doc.config.yaml`](../repository/config.mdx).

## Antes de añadir uno

- Busca un tipo existente que encaje; crea uno solo cuando ninguno sirva.
- Tras cambiar un `_type.yaml`, las entidades existentes deben seguir validando: un campo obligatorio nuevo tiene que rellenarse en todas ellas.
