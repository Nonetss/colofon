## Las páginas que genera

No hay que escribir MDX para ellas: la plataforma las construye a partir del catálogo cada vez que lee el sitio.

| Ruta | Qué muestra |
| --- | --- |
| `catalog` | Todos los tipos, con cuántas entidades tiene cada uno y cuántas tienen página |
| `catalog/<type>` | La tabla del tipo, con sus `vista.columnas`: se ordena, se filtra por columna, se pagina y se exporta como cualquier tabla |
| `catalog/<type>/<id>` | Una entidad: sus campos, su página, las páginas que la citan, las entidades que apuntan a ella y los diagramas en los que aparece |

Las de este sitio están bajo "Referencia" en la barra lateral. Abre [Ficheros](catalog:files) y después [menu.yaml](catalog:files/menu): la página de la entidad lista las páginas de esta guía que la citan y el diagrama del que es una caja.

## La página de una entidad

- **Sus campos,** cada uno mostrado según su tipo: referencias y páginas como enlaces, listas unidas, booleanos como "Sí" o "No". Después `fuente`, cuando la tiene.
- **Página:** la página que nombra su primer campo `ficha`, cuando lo tiene.
- **Páginas que la citan:** toda página cuya cabecera la nombra en un campo `ref`, o cuyo texto enlaza a ella.
- **Referencias:** por cada tipo con un campo `ref` que la nombra, la tabla de esas entidades. La página de una máquina muestra los stacks que se ejecutan en ella y las VM que aloja.
- **Diagramas:** todo diagrama que la tiene como caja.

## Cómo llegar

- Los enlaces `catalog:`: a la página de la entidad cuando la tiene, y si no, a su página de catálogo.
- La etiqueta de cada fila de una tabla `Entities`, y cada celda de referencia.
- El menú: `catalog` muestra el catálogo con todos los tipos, `catalog/machines` un tipo. Sin `menu.yaml`, el catálogo es la última sección de la barra lateral.

Las páginas de entidad no aparecen en la barra lateral; las de tipo sí, y el buscador las encuentra. Cada una tiene su Markdown para agentes, como cualquier página.
