## Sin menú

Sin `menu.yaml`, la barra lateral son las carpetas de `docs/`: cada carpeta es una sección, ordenada por el `orden` de su `index.mdx` y luego por título, y el catálogo va al final. Funciona, pero agrupar las páginas de otra manera obliga a mover ficheros, y mover un fichero cambia su URL.

## Con menú

`menu.yaml` lista los grupos de la barra lateral, en orden. Cada grupo tiene un título, un icono, una descripción y sus entradas:

```yaml
secciones:
  - titulo: Infraestructura
    icono: server
    descripcion: Las máquinas y la red
    paginas:
      - network                                   # una carpeta, con todas sus páginas
      - { ruta: containers/komodo, icono: layers } # con su propio título o icono
      - backups/duplicati/create-backup             # una sola página
  - titulo: Datos
    icono: database
    paginas: [catalog]                           # el catálogo; o catalog/machines
```

| Clave | Qué es |
| --- | --- |
| `secciones` | Los grupos, al menos uno. |
| `titulo` | Obligatoria. El título del grupo en la barra lateral. |
| `icono` | Opcional. El nombre de un icono de Lucide. |
| `descripcion` | Opcional. Una frase sobre qué contiene el grupo. |
| `paginas` | Obligatoria. Sus entradas: una ruta, o `ruta` con un `titulo` e `icono` opcionales. |

Una entrada nombra una página (`network/dns`), una carpeta de `docs/` (`network`, que trae todas sus páginas en su orden habitual), el catálogo (`catalog`) o un tipo del catálogo (`catalog/machines`). **Las carpetas guardan las páginas; el menú decide dónde se muestran.** Un grupo puede reunir carpetas de cualquier sitio, y cada página conserva su URL.

El menú de este propio sitio es un buen ejemplo: consulta su `menu.yaml`.

## El menú manda

Lo que el menú dice de una entrada es lo que muestra cada vista: la barra lateral, la cabecera de la página, las migas de pan, las tarjetas, la búsqueda y `llms.txt`. La cabecera de una página solo cuenta para lo que el menú deja sin decir.

- `{ ruta: network, icono: network }` da a la sección su icono; el `icono` de `docs/network/index.mdx` se ignora entonces.
- Cuando la cabecera dice otra cosa, la página se reporta ("la cabecera dice…, pero manda menu.yaml"), para que nadie edite un valor que nunca se muestra.
- Las migas de pan empiezan por el grupo, como texto plano: un grupo es un encabezado, no una página.

## Qué se reporta

- Una entrada que no nombra nada, la página de inicio, o algo que una entrada anterior ya muestra (la misma ruta, una carpeta que la contiene o una página dentro de ella): se reporta y se omite. El resto del menú se usa.
- Una página o tipo del catálogo que ninguna entrada muestra: se lista en un último grupo, **"Otros"**, y se reporta en la página. Nada de lo escrito se pierde de la barra lateral.
- Un `menu.yaml` mal formado (una clave desconocida, un título que falta, un icono que Lucide no tiene): es una declaración, así que la plataforma mantiene la última versión válida hasta que se corrija.

Los problemas de `menu.yaml` se muestran a los administradores en la página de inicio del repositorio.
